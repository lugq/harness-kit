# Harness 文档审计

执行前读取 [审计流程](references/audit.md)。默认只检查并在聊天中报告，不修改任何项目文件，不追加 verification.md，不生成项目内报告，不提交、不执行初始化或业务测试。用户要求修复时作为后续明确授权的维护任务处理，不在检查过程中顺手修复。

先读取适用项目指令，确认真实知识目录和索引；默认 .harness，自定义目录沿用现有入口，不能扫描其他旧知识系统作为来源。执行本 Skill 的 scripts/audit.py 获取结构问题，再人工阅读相关文档检查职责与证据。脚本成功不代表内容正确；没有核对源码时明确标注“未做源码一致性检查”。

索引允许简短介绍、用途、读取条件与导航；详细功能流程、接口字段、状态机和错误矩阵应在对应 Feature/Spec。不能仅凭字数、标题或某个代码块就定为错误，应引用实际段落解释混用原因。按需只读核对相关源文件和符号，不为审计运行业务代码、安装依赖或读取无关资料。

报告区分确定问题、待人工确认风险、未检查项，逐项给出位置、证据、影响和建议修复位置；列明检查范围及工具限制。没有发现问题也不能声称全项目源码与文档完全一致。
