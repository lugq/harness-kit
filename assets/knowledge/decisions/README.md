# 决策记录指南

重要设计取舍需要长期追溯时创建记录；普通实现细节不必新建决策。

文件命名为三位递增编号与英文主题，如 001-topic.md。先检查现有编号，避免重复。

状态使用：待确认、已采纳、已废弃、已替代。建议不能直接标为已采纳；记录确认依据。替代旧决策时保留历史并双向关联。

## 决策模板

```markdown
# 决策标题

编号：待填写
状态：待确认
日期：待填写
## 问题与背景
需要解决的问题、约束及证据。
## 候选方案
可行选择与各自的收益、成本和限制。
## 选择与理由
建议或已确认选择，以及取舍依据。
## 影响
受影响的模块、接口、迁移范围与风险。
## 确认依据
确认记录；未确认时明确标注。
## 关联
相关架构、功能、规范与被替代的决策。
```

创建记录后在 ../index.md 登记；状态变化时同步受影响的文档。
